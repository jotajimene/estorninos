# Estorninos

Un enjambre de palabras a partir de «Rebeldía y descarrío: una entrada breve sobre lo posible», de Saidiya Hartman (*Vidas rebeldes, experimentos hermosos*).

Desde el cuarto, mira hacia afuera y suelta una palabra. Cada palabra se vuelve un estornino; la bandada traza una ruta que nadie dirige.

- Participar: https://jotajimene.github.io/estorninos/
- Proyección en clase: https://jotajimene.github.io/estorninos/?sala

Seminario *Ensamblajes especulativos*, USACH. Jota Jiménez, 2026.
